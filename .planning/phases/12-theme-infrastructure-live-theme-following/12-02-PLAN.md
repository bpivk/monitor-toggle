<objective>
Wire the finished theme infrastructure into the composition root and the always-visible flow: call `Application.SetColorMode(SystemColorMode.System)` as the first line of `Main()`, construct the single `WindowsThemeProvider`, inject it into every form, and give MainForm + MonitorConfirmDialog full launch-time + live-follow theming (title bar, standard controls, flat buttons, Windows-11 Mica/rounded corners). SettingsForm receives only its constructor parameter here so the composition root compiles; its per-control gap work lands in plan 12-03.

Output: Program.cs base wiring + MainForm/MonitorConfirmDialog fully themed + SettingsForm ctor threaded.

Task ordering note (constructor-then-callsite discipline): each form's `IThemeProvider` constructor parameter is added by the SAME task that updates that form's construction call-site, so `dotnet build` stays green at every task boundary. <threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| OS event thread → form UI thread | `IThemeProvider.ThemeChanged` may arrive off the UI thread; touching controls cross-thread throws |
| Managed → native (dwmapi.dll) | DWM chrome applied per-form on an OS that may not support the attributes |
| Long-lived provider → transient dialog | `WindowsThemeProvider` outlives `MonitorConfirmDialog`; a retained handler leaks the dialog |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-12-02 | Denial of Service | MainForm/MonitorConfirmDialog OnThemeChanged | mitigate | Every handler marshals via `InvokeRequired`/`BeginInvoke` before touching controls (A3); body wrapped in try/catch so a theming failure never crashes the toggle/confirm flow. |
| T-12-03 | Tampering | DwmTitleBar.ApplyRoundedCornersAndMica call sites | mitigate | Called only after `Handle` exists (InitializeTrayState for MainForm per D-08; post-InitializeComponent for the always-shown dialog); best-effort non-throwing HRESULT from plan 12-01, no crash on Windows 10. |
| T-12-05 | Denial of Service | MonitorConfirmDialog ThemeChanged subscription lifecycle | mitigate | Transient dialog unsubscribes on `FormClosed`; MainForm unsubscribes in Dispose — prevents leaked handlers on the app-lifetime provider (flagged pitfall). |
| T-12-06 | Tampering | Program.cs SetColorMode ordering | mitigate | `SetColorMode` is the first `Main()` statement, before any UI construction, avoiding the double-DWM-attribute title-bar flash (Pitfall 1). |
| T-12-SC | Tampering | npm/pip/cargo installs | accept | Zero new packages (12-RESEARCH.md Package Legitimacy Audit); no supply-chain surface. |
</threat_model>
