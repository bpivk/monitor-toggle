<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| OS event thread → SettingsForm UI thread | `ThemeChanged` may arrive off the UI thread while Settings is open |
| Long-lived provider → transient SettingsForm | Fresh-per-open dialog subscribing to an app-lifetime provider |
| Managed → native (dwmapi.dll) | DWM chrome on a possibly-unsupported OS |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-12-02 | Denial of Service | SettingsForm.OnThemeChanged / ThemeApplier | mitigate | Marshal via `InvokeRequired`/`BeginInvoke` before touching controls; ThemeApplier + OnThemeChanged bodies wrapped in try/catch (cosmetic-only, must not crash Settings save/load). |
| T-12-05 | Denial of Service | SettingsForm ThemeChanged subscription lifecycle | mitigate | `FormClosed` unsubscribe on the fresh-per-open dialog prevents the app-lifetime `WindowsThemeProvider` from leaking closed SettingsForm instances. |
| T-12-07 | Tampering | GroupBox→Panel drag-drop re-parenting | mitigate | `AppPath_DragEnter`/`AppPath_DragDrop`/`AllowDrop` explicitly moved to the replacement Panel; build failure surfaces any orphaned handler/child reference. |
| T-12-03 | Tampering | DwmTitleBar on SettingsForm | mitigate | Best-effort non-throwing HRESULT (plan 12-01); applied only after Handle exists; silent Windows-10 no-op. |
| T-12-SC | Tampering | npm/pip/cargo installs | accept | Zero new packages (12-RESEARCH.md Package Legitimacy Audit). |
</threat_model>
