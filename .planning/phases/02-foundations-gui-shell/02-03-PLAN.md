| Native COM/CCD APIs → managed adapter | WindowsDisplayAPI/NAudio marshal native display/audio state into managed objects |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-APPEXEC | Elevation/Tampering (deferred) | IsRunning path handling | accept (this phase) | Detection is read-only (GetProcessesByName); no Process.Start occurs until Phase 3, where `.exe`-existence validation (already gated at Settings save-time in Plan 04) precedes any execution |
