<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| User file-picker input → persisted CompanionAppPath | The chosen executable path is validated before it is written to settings.json |
| Persisted settings → enumerated hardware | A saved device/path ID may no longer resolve on reopen — must degrade gracefully, not crash |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-BADPATH | Tampering / arbitrary-executable pointer | CompanionAppPath save-time validation | mitigate | Save requires `File.Exists` + `.exe` extension (appPathOk); a non-.exe/missing path cannot be persisted — the V5 input-validation gate for the Phase-3 Process.Start (02-RESEARCH.md Security Domain lines 519-521, 528) |
| T-02-STALECRASH | Denial of Service | Reopening Settings after a saved device/path disappears | mitigate | Stale-selection handled as unselected + inline warning (D-10); audio ID resolution guarded in Plan 03; no unhandled exception on missing IDs |
| T-02-FIRSTRUN | (UX correctness, not security) | First-run warning suppression | mitigate | Null saved ID → no D-10 warning (Pitfall 3) — prevents a false "corruption" signal on a clean install |
</threat_model>
