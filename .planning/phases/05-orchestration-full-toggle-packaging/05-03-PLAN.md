<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Build tier (MSBuild publish) → shipped exe | Publish flags determine which native/managed components are bundled and whether trim-analysis alters COM/P-Invoke code paths. |
| Single-file exe → %TEMP% self-extraction | The .NET host's native components extract to `%TEMP%\.net\<app>\<hash>` on first run of a given build. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-05 | Tampering | IL trimming silently stripping IPolicyConfig COM interop / WindowsDisplayAPI P/Invoke marshalling | mitigate | Explicitly set `<PublishTrimmed>false</PublishTrimmed>` in win-x64.pubxml (Task 1) per CLAUDE.md; trimming is opt-in only, so false is both the default and a documented guard against future accidental reintroduction (RESEARCH Pitfall 3). |
| T-05-06 | Tampering | Native self-extraction to `%TEMP%\.net` writable by a lower-privileged principal | accept | Single-user Windows machine with a per-user `%TEMP%`; no second principal to plant a malicious component. Standard .NET single-file behavior; not an elevated risk for this threat model (RESEARCH Security Domain). |
| T-05-07 | Elevation of Privilege | Publish config inadvertently adding an admin/elevation manifest | mitigate | Task 1 explicitly preserves the asInvoker posture (no execution-level/manifest added); broad elevation would break cross-process companion-app window focus via UIPI (STATE.md blocker) — acceptance criteria assert no elevation manifest is added. |
| T-05-SC | Tampering | npm/pip/cargo installs | accept | No package-manager installs and no new NuGet packages this plan (MSBuild property config only — RESEARCH Package Legitimacy Audit N/A). Nothing to audit. |
</threat_model>
