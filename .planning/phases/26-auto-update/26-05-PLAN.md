<objective>
Give the user a way to ask for an update check on demand, from both the tray menu and Settings,
that reports honestly whether it succeeded — then verify the whole phase on real hardware.

Purpose: UPDATE-06 and D-05/D-06/D-07. The automatic check is deliberately silent on failure
because nobody asked for it; a manual check is the opposite case, and D-07 is explicit that a
failed manual check must not look identical to "you're already up to date". This plan also
carries the phase's operator verification, because the swap, the reboot-autostart survival, and
the interrupted-update recovery are all things no automated test in this repository can produce.

Output: `UpdateOrchestrator.CheckOnDemandAsync`, one shared `PerformManualUpdateCheck` in
`MainForm` reached from two entry points, the tray menu item, the Settings button, and a
blocking rig-verification checkpoint covering every requirement in the phase.
</objective>
