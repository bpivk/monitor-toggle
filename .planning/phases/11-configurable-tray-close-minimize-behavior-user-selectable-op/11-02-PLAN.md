<objective>
Make MainForm's window-close and minimize behavior settings-driven, and make the tray icon's presence a derived value of the two Phase 11 preferences. This replaces Phase 8's unconditional "X always hides to tray, minimize is always standard OS" behavior.

Purpose: Deliver the actual runtime behavior change for TRAY-01's revision (D-01, D-04) and the derived tray-icon-existence rule (D-08–D-11) — the plan that turns the two new AppSettings booleans into observable window behavior.

Output: A shared `SendToTray()` hide helper used by both the Close and Minimize paths, a conditional `MainForm_FormClosing`, a public `ApplyTrayVisibility()` derived-visibility helper wired into startup, a new `MainForm_Resize` minimize-to-tray handler, and the Designer wiring (Resize subscription + `notifyIcon.Visible` default flipped to false so startup derives it).
</objective>
