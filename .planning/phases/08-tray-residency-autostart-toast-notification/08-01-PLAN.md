## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-08-DOS | Denial of Service | `StartupArgs.ShouldStartHidden` | mitigate | Predicate is a bare `Contains` with no indexing/parsing; unit-tested against empty/garbage args so a malformed autostart invocation cannot crash the composition root (which would silently fail every login). |
| T-08-INJ | Tampering/Injection | Run-key value construction in `Enable()` | accept | The value is `"{Environment.ProcessPath}" --tray` — `ProcessPath` is OS-supplied, not user-controllable input; there is no untrusted string interpolated into the command. No injection surface. Quoting the path guards against spaces in the install directory. |
| T-08-EOP | Elevation of Privilege | Registry hive selection | mitigate | Always `Registry.CurrentUser`, never `LocalMachine`; a source assertion forbids `LocalMachine`. Preserves the app's asInvoker, non-elevated model (CLAUDE.md constraint, v1.0 H9 UIPI workaround). |
| T-08-SC | Tampering | npm/pip/cargo installs | n/a | This plan adds zero external packages (per 08-RESEARCH.md Package Legitimacy Audit: not applicable). No install tasks. |
