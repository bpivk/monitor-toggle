<objective>
Give the user the actual control: a System/Light/Dark radio group in the slot Phase 22 reserved, applying live the moment it is clicked, persisting only on Save, and reverting on Discard or close.

Purpose: 23-01 made a persisted value lock the whole app's theme, but the only way to set that value today is hand-editing `settings.json`. This plan replaces that with the real entry point and adds the one interaction that makes this field deliberately different from every other field in the form (D-01: apply before Save).
Output: the radio group in `SettingsForm.Designer.cs`, its state/Save/revert wiring in `SettingsForm.cs`, and two new callback arguments threaded from the composition root.
</objective>
