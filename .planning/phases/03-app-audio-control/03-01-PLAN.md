<objective>
Expand the audio snapshot from a single `DefaultDeviceId` to a per-role structure (D-02) so that toggle-back can restore the exact previous default device across all three Windows audio roles (AUDIO-02, "across all relevant audio roles"). This is the foundational contract change every audio-restore path in Plan 02 builds on.

Purpose: Phase 2 captured only `Role.Multimedia`. AUDIO-02 and PITFALLS Pitfall 5/7 require capturing eConsole, eMultimedia, and eCommunications separately so restore is exact. This plan reshapes the model, expands `CaptureState`, keeps every positional call site compiling, and adds a defensive `Load()` guard for the now-breaking on-disk shape (Open Question 1).

Output: Reshaped `AudioState`/new `AudioRoleState`, per-role `CaptureState`, defensive `JsonSnapshotStore.Load`, updated `FakeAudioController`, green test suite.
</objective>
