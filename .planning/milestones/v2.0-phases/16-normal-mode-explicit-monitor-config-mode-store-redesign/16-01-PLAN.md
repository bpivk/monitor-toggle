| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-16-01 | Tampering / Denial of Service (local) | JsonModeStore.TryLoad / JsonToggleInProgressStore.TryLoad | mitigate | Both `TryLoad()` implementations catch `JsonException` AND `IOException` and return null, degrading a malformed/hand-edited/truncated file to the well-defined "corrupted" state (Plan 04's D-06/D-07 dialog handles the mode-file case) rather than an unhandled startup crash — the same posture already proven for settings.json/state.json. |
| T-16-02 | Tampering (accidental, crash mid-write) | JsonModeStore.Save / JsonToggleInProgressStore.Save | mitigate | Atomic temp-file + `File.Move(overwrite: true)` idiom copied verbatim from JsonSnapshotStore — an interrupted write only ever corrupts the `.tmp` sibling, never the previous good file. |
| T-16-SC | Tampering | npm/pip/cargo installs | accept | No packages added this phase (RESEARCH Package Legitimacy Audit: N/A — `System.Text.Json` is BCL). Nothing to verify. |
