    - Save then Load round-trips every AppSettings field value identically.
    - Save writes to a `.tmp` sibling then File.Move(tmp, final, overwrite: true) — after a Save over an existing file, only the final file remains (no leftover .tmp) and its content is the new value.
    - JsonSnapshotStore.Exists() is false before any Save and true after Save; Clear() deletes the file so Exists() returns false again; Load() returns null when absent, the saved StateSnapshot when present.
  </behavior>
  <action>

Use `System.Text.Json` with `WriteIndented = true` for settings. Load creates a fresh `AppSettings()` when the file is missing.
