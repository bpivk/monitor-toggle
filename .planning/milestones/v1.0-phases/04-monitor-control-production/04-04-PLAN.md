<objective>
Add the DISPLAY-03 safety confirmation before the primary monitor is disabled. Per D-01 this is a durable "show once" prompt with a "don't ask again" checkbox persisted to settings — a small custom WinForms dialog (MessageBox has no checkbox), not a per-toggle prompt. Per D-02 the remembered preference resets automatically when the configured monitor changes, so the user always gets exactly one fresh confirmation naming the newly-configured display and never a stale consent carried to a different monitor.

This plan is independent of the monitor-mechanism work (Plans 02/03): it touches only the App tier + one persisted settings field, and reads the already-real `GetActiveMonitors()`/`SkipMonitorConfirmation`. It wires a new `IMonitorController` dependency into `MainForm` through the composition root so the dialog can name the monitor by friendly name.

Purpose: Deliver DISPLAY-03 — informed consent naming the monitor about to be disabled.
Output: A reusable confirmation dialog, a persisted skip flag, and the MainForm/Settings wiring that governs it.
</objective>
