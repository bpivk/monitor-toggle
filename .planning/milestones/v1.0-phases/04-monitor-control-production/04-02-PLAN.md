<objective>
Reshape the monitor snapshot contract from Phase 2's minimal single-device-path `MonitorState` into a full-topology, JSON-serializable shape that supports DISPLAY-02's "restore to exact prior configuration" — because Plan 03's repositioning-aware disable shifts EVERY surviving path's coordinates, so restore must undo that for every display, not just re-activate the disabled one.

This is the contract-and-capture layer. It defines the new models, changes `IMonitorController.CaptureState()` to take no parameter (mirroring the Phase 3 `IAudioController` precedent), implements the real full-topology `CaptureState()` in the Windows adapter (leaving `Disable`/`Restore` as compiling no-op stubs for Plan 03 to fill), and ripples the shape change through the ToggleService call-site, the test double, and the persistence round-trip tests. It keeps the build and all Core tests green so Plan 03 and Plan 04 build on a stable contract.

Purpose: Establish the durable snapshot shape (contracts first) that Plan 03's Disable/Restore consume.
Output: New primitive models, a no-param capture interface, real CaptureState, and a green build/test suite.
</objective>
