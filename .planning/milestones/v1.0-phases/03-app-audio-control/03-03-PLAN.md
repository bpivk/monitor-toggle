<objective>
Replace the `LaunchOrFocus`/`MinimizeIfRunning` no-op stubs with real Win32 process/window control (APP-01/02/03) and insert the D-05 app-path preflight as the first mutating-path check in `ToggleToRigMode` so a missing companion app fails fast with nothing yet touched. This plan is fully independent of the audio work (Plans 01/02) and runs in parallel.

Purpose: APP-01 (launch if not running), APP-02 (focus existing window, no duplicate), APP-03 (minimize on toggle-back, best-effort), plus D-05 ordering safety. The two pitfalls that bite naive implementations are `MainWindowHandle` caching (needs `Refresh()` each poll) and treating a best-effort `SetForegroundWindow` failure as an error.

Output: New `NativeMethods.cs`, real `WindowsAppController` mutation methods, D-05 preflight in `ToggleService`, and a preflight regression test.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| user-configured CompanionAppPath → Process.Start | app launches an executable named by persisted settings |
| RigToggle process → another process's window (SetForegroundWindow/ShowWindow) | cross-process window manipulation across UIPI |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-08 | Elevation of Privilege | Process.Start of a user-configured .exe path | accept | Single-user personal tool; the path is chosen by the same user via the Settings .exe browse dialog; launched at the app's own (asInvoker, non-elevated) integrity level — no privilege boundary is crossed. CLAUDE.md forbids an elevation manifest precisely to keep parity with the target window |
| T-03-09 | Tampering (TOCTOU) | File.Exists preflight then later Process.Start of CompanionAppPath | accept | The D-05 preflight is a fail-fast UX guard, not a security control; a path swapped between check and launch on a single-user local machine is out of scope (no adversary in the single-user threat model) |
| T-03-10 | Denial of Service | Refresh()-less poll loop spinning forever on IntPtr.Zero (Pitfall B) | mitigate | Task 1 calls process.Refresh() before every MainWindowHandle read and bounds the loop with a 10s deadline; timeout returns without failing the toggle (D-06) |
| T-03-11 | Spoofing | Cross-process SetForegroundWindow silently failing (taskbar-flash fallback) | accept | Documented, expected Win32 behavior at matching integrity levels (D-07/ARCHITECTURE.md treat best-effort focus as acceptable); no AttachThreadInput bypass added |
| T-03-SC | Tampering | npm/pip/cargo installs | mitigate | No packages installed (user32 P/Invoke is OS surface, not a NuGet package; RESEARCH Package Legitimacy Audit: N/A) |
