<objective>
Implement the generalized `IMonitorController` triad in the real Windows CCD adapter: `GetAllMonitors()` (active + OS-disabled-but-available), `ActivateMonitors(set)` (Extend-based, D-01), and `DeactivateMonitors(set)` (the existing repositioning-aware `Disable()` logic generalized 1→N), and N-generalize `Restore()`'s verification with a bounding-box overlap check. Every genuinely hard problem here already has a proven, rig-validated solution one level up in this same file — the work is generalization and re-query/verify discipline, NOT new native-API discovery.

Purpose: This is the only tier that can see and mutate OS-disabled monitors; it makes DISPLAY-04 (N-monitor disable) and DISPLAY-05 (enable a normally-disabled monitor) physically real.
Output: Updated `WindowsMonitorController` fully implementing the new interface, plus pure-logic overlap-helper tests.

ENVIRONMENT: `RigToggle.Windows` is `net10.0-windows` and only builds on the Windows rig (it references `WindowsDisplayAPI`/WinForms). A non-Windows executor CANNOT run `dotnet build` here — verify via the source assertions in each `<acceptance_criteria>` and defer the real build + CCD behavior to the Windows rig and the Plan 06 rig-validation checkpoint.
