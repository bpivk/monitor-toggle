    2.     4. EXE/TASKBAR ICON (ICON-04): Confirm the taskbar button, Alt-Tab entry, and Explorer file icon for RigToggle.App.exe all show the color monitor motif (dark-gray monitor with a blue screen), matching the normal-mode tray motif at a larger size — not a stale default or unrelated glyph. Right-click → Properties / hover Alt-Tab to check the larger (48/256px) frames look sharp too.
  </how-to-verify>
